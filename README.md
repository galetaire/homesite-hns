# How-to guides for Handshake users

[Handshake](https://handshake.org/) is an experimental DNS root zone built on a peer-to-peer (P2P) blockchain. In short, it’s an alternative DNS. This repo collects practical onboarding guides for using Handshake in an approachable, self-hosted and sovereign way, from resolving names to serving a static site over HTTPS.

- **[Fingertip](https://galetaire.github.io/homesite-hns/fingertip.html)**: Resolve Handshake addresses
- **[Bob Wallet](https://galetaire.github.io/homesite-hns/bobwallet.html)**: Store and manage your names on your PC or [Umbrel](https://umbrel.com/)
- **[Finestra](https://galetaire.github.io/homesite-hns/finestra.html)**: A self-hosted explorer for your [Umbrel](https://umbrel.com/)
- **[Yeil DNS](https://galetaire.github.io/homesite-hns/yeil.html)**: Host an http site on [GitHub Pages](https://github.com/)
- **[Castell](https://galetaire.github.io/homesite-hns/castell.html)**: Host a static https+DANE site on your [Umbrel](https://umbrel.com/)
- **[Coins faucet](https://galetaire.github.io/homesite-hns/faucet.html)**: Get a small amount of Handshake coins, so you can get started

> **Note:** I do not recommend crypto investment whatsoever. Skepticism around blockchain projects is more often right than wrong, but I consider HNS DNS to be a decent exception, and a valid alternative to ICANN DNS.
