A functional guide for Handshake users

Finestra is a self-hosted Handshake explorer that runs on your Umbrel and reads its data directly from your own Bob DNS full node.

How to explore Handshake from your Umbrel

Note: UmbrelOS is an open-source, Debian-based operating system designed to turn a computer, mini PC, Raspberry Pi or server into a user-friendly personal cloud and self-hosting hub. Its key features are a simple web interface easy to manage from your browser, and a plentiful App Store.

0. What you need

  • A computer running UmbrelOS.
  • Bob DNS, running a full node, preferably already fully synced.

1. Installing Finestra

Before installing Finestra, you need to install Bob DNS, run it in full node mode and, ideally, wait until the node is fully synced. This is required because Finestra reads its data from the Bob DNS full node. Once these steps are done, installing Finestra is as simple as installing any other Umbrel app: go to App Store → Community App Stores → Manage, paste https://github.com/galetaire/finestra and install Finestra.

2. The umbrelOS Handshake ecosystem

Why umbrelOS? I find it to be one of the best ways to have a hub at home, not just for running Bitcoin or Handshake apps, but also for managing things like Nextcloud, Pi-hole and other apps that need to run 24/7, all with very low power consumption.

Its convenience as a home server and how easy it is to port apps to it make it a perfect fit for the Handshake ecosystem. That's the main reason I started porting Handshake apps. These are the Handshake apps you can currently install on Umbrel:

  • Bob DNS, a Handshake wallet and full node: https://github.com/galetaire/bob-dns
  • Finestra, a self-hosted Handshake explorer: https://github.com/galetaire/finestra
  • Castell, a website host with DANE support: https://github.com/galetaire/castell

They aren't in the official App Store yet, but I'm gradually submitting them and hope they'll be published eventually. In the meantime, they're very easy to install as community apps.

My plan is to keep bringing more Handshake apps to Umbrel, apps that help the project grow and contribute to a more sovereign internet. I encourage anyone who has a spare computer or Raspberry Pi (8 GB of RAM minimum recommended) to try Umbrel out and install these Handshake apps.

If you have ideas for apps that would be good for Handshake, let me know and we can explore bringing them over together to grow the ecosystem.
