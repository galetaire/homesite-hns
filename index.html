A first guide for handshake users 📖

Welcome! This site is intended for users who want to explore and be part of the Handshake DNS, an alternative DNS system.

  • Fingertip: how to resolve Handshake addresses
  • Bob Wallet: how to store and manage your names
  • GitHub: how to host an http site on GitHub Pages
  • Umbrel + Castell : how to host an https+DANE site on your Umbrel
- You can fork this site on github.com/galetaire.
